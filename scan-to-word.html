Scan to Word (OCR)

Read text from scanned PDFs and photos and save it as an editable Word file.

    How to use it

    1. Pick the language of the document.
    2. Choose a PDF or photo. Try one page first, it is slow on phones.
    3. Tap Convert, then Download the DOCX and proofread it.

    About this tool

    Scan to Word uses OCR (text recognition) to read each page as a picture. It works on scanned PDFs and on PDFs whose text comes out garbled, which is common with Urdu files made in older tools. Results depend on print quality. Urdu in Nastaliq style is hard for OCR, so always proofread.

    Questions

    Why did PDF to Word give strange characters?

    Some PDFs, often Urdu ones, store their text in a custom font that cannot be read as normal text. OCR reads the page as a picture instead.

    How accurate is it?

    Good on clear printed text, weaker on small, blurry or Nastaliq-style Urdu. Always proofread the result.

    Is my file uploaded?

    No. Your document stays on your device. The first run only downloads language data for the OCR engine.
